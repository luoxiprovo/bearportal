# Installation and release evidence

[2026-11-05 SSH development installation](2026-11-05-ssh-install.md) records the limited live run and its local script overrides. It is not a completed beta-release qualification.

For future records, include the date, environment, resolved artifact commit, local overrides, operation IDs, commands/checks actually performed and remaining gaps. Separate installer acceptance, later HTTPS checks and mail-delivery evidence. Never include credentials or private keys.

The current API checklist is hardcoded incomplete; adding a document does not update it. Automated coverage is summarized in [../local-validation.md](../local-validation.md).
